# Claude Prototypes

Self-contained, no-server web app prototypes. Each app is a single HTML file — open it directly in a browser (`file://` works) or host it on GitHub Pages.

## Apps

| App | File | Description |
|---|---|---|
| 📡 ReturnRadar | [`returnradar.html`](returnradar.html) | Never miss a return window or warranty again. Log a purchase in seconds (store presets auto-fill typical return windows) and get urgency-colored countdowns for every deadline, money-at-stake stats, calendar (.ics) reminders, and JSON backup. 100% private — all data stays in the browser's local storage. No account, no server, works offline. |
